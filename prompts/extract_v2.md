你是中国刑事判决书的信息抽取助手。下面给出一份盗窃案一审判决书的若干段原文（当事人段、本院认为段、判决段；段落缺失时给出全文开头）。请只针对**第一被告人**（当事人段里第一个出现的"被告人××"），抽取下列 7 个字段。

总原则：
1. 只依据原文，不推断。原文没写的一律填 "NA"。
2. 取值必须严格来自下面给出的取值，不得自造。数字只写阿拉伯数字。
3. evidence 是支撑该答案的原文摘录，不超过 20 个字；标明"evidence 留空"的字段，evidence 填 ""。答案为 NA 时 evidence 填 ""。
4. 只输出一个 JSON 对象，不要任何解释。

字段与规则：
- origin_text：第一被告人的来源地原文。**只能**取以下三种写法中的地名，按优先级取第一个出现的：
  (1) "户籍地 / 户籍所在地 / 户口所在地"后面的地名；
  (2) "出生于 / 生于 ××"中的地名；
  (3) "××省××县人"这种籍贯写法中的地名。
  原样抄录地名本身（不含"户籍地""出生于""人"等字）。都没有时填 "NA"。evidence 留空。
  **禁止把住址当作来源地**："住、现住、暂住、住所地、家住、捕前住址"后面的地名只能填进 residence_text，不能填进 origin_text。
  - 正例："被告人莫某，男，1984年3月18日出生于贵州省荔波县，住福清市龙田镇" → origin_text = "贵州省荔波县"。
  - 反例："被告人莫某，男，1984年3月18日出生，布依族，住贵州省荔波县" → 没有户籍、出生地、籍贯，origin_text = "NA"（"贵州省荔波县"是住址，填进 residence_text）。
- residence_text：第一被告人的住址原文，即"住、现住、暂住、住所地、家住、捕前住址、现住址"后面的地名，原样抄录。写"户籍地及现住址××"的，住址也填"××"。没有时填 "NA"。evidence 留空。
- status_at_judgment：判决时第一被告人的强制措施状态，取值 "在押" / "取保" / "监视居住" / "其他" / "NA"。
  - 以当事人段中"现羁押于……""现押于……""现取保候审""现被监视居住""现在家"等**写明当前状态**的句子为准；没有这类句子时，取当事人段中最后一个强制措施事件（如"……被逮捕"为在押，"……被取保候审"为取保）；写"现在家"且此前取保的，算"取保"。
  - **禁止根据判决段的刑期折抵套话推断状态**。"判决执行以前先行羁押的，羁押一日折抵刑期一日""即自××起至××止"只说明被告人**曾经**被羁押过，不能说明判决时在押。当事人段既没有写当前状态、也没有任何强制措施事件时，填 "NA"。
  - 正例："2019年3月1日被刑事拘留，同月15日被逮捕。现羁押于某看守所。" → "在押"。
  - 反例：当事人段只有"被告人王某。"，判决段写"判决执行以前先行羁押的，羁押一日折抵刑期一日，即自2019年3月1日起至……止" → "NA"。
- ever_bail：第一被告人在任何阶段被取保候审过为 "1"，否则 "0"。
- penalty_type：第一被告人的主刑，以判决主文为准，取值 "有期徒刑" / "拘役" / "管制" / "单处罚金" / "免予刑事处罚" / "其他"。evidence 留空。
- term_months：主刑期限折算成月的数字（如"一年六个月"为 18）；不含缓刑考验期；数罪并罚取"决定执行"的刑期；没有期限（如单处罚金）填 "NA"。evidence 留空。
- probation：第一被告人被宣告缓刑为 "1"，否则 "0"。evidence 留空。

输出格式（所有 value 都用字符串）：
{"origin_text": {"value": "...", "evidence": ""}, "residence_text": {"value": "...", "evidence": ""}, "status_at_judgment": {"value": "...", "evidence": "..."}, "ever_bail": {"value": "...", "evidence": "..."}, "penalty_type": {"value": "...", "evidence": ""}, "term_months": {"value": "...", "evidence": ""}, "probation": {"value": "...", "evidence": ""}}
