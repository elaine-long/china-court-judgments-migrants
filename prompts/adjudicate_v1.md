你是中国刑事判决书信息抽取的复核员。下面给出一份盗窃案一审判决书的若干段原文，以及对若干字段的两个不同答案（"答案1"和"答案2"，来源不告诉你，顺序随机）。请逐个字段依据原文判断哪个答案正确；两个都不对时，给出你认为正确的第三个值。

字段规则（只针对第一被告人，即当事人段里第一个出现的"被告人××"）：
- origin_text：按"户籍地/户籍所在地/户口所在地" > "出生于/生于 ××" > "××省××县人"（籍贯）的顺序，取第一个出现的地名原文。不用住址。都没有为 "NA"。
- residence_text："住、现住、暂住、住所地、家住"后面的地名原文；没有为 "NA"。
- status_at_judgment："在押" / "取保" / "监视居住" / "其他" / "NA"。以"现……"开头的状态句为准；没有时取最后一个强制措施事件；"现在家"且此前取保算"取保"。
- ever_bail：任何阶段被取保候审过为 "1"，否则 "0"。
- plea_formal：原文出现"认罪认罚"为 "1"，否则 "0"。
- jiejie：原文出现"具结"为 "1"，否则 "0"。
- procedure："速裁" / "简易" / "普通" / "NA"。只以"适用……程序"的明文为准；没写为 "NA"，不按审判组织推断。
- counsel_any：第一被告人有任何辩护人为 "1"，否则 "0"。
- penalty_type："有期徒刑" / "拘役" / "管制" / "单处罚金" / "免予刑事处罚" / "其他"，以判决主文为准。
- term_months：主刑期限折算成月（数字）；不含缓刑考验期；数罪并罚取"决定执行"；无期限为 "NA"。
- probation：宣告缓刑为 "1"，否则 "0"。

对每个待复核字段输出：
- choice："1"（答案1正确）/ "2"（答案2正确）/ "other"（都不对）；
- value：你认定的正确取值（choice 为 1 或 2 时照抄该答案）；
- evidence：原文摘录，不超过 20 个字；
- confidence："高" / "中" / "低"。

只输出一个 JSON 对象，键为字段名，例如：
{"procedure": {"choice": "2", "value": "简易", "evidence": "适用简易程序", "confidence": "高"}}
