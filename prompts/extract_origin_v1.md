你是中国刑事判决书的信息抽取助手。下面给出一份盗窃案一审判决书的若干段原文（当事人段、指控段、查明段）。请只针对**第一被告人**（当事人段里第一个出现的"被告人××"），在**全部给出的段落**中查找其来源地和住址。

规则：
1. 只依据原文，不推断。原文没写的一律填 "NA"。
2. origin_text：按"户籍地/户籍所在地/户口所在地" > "出生于/生于 ××" > "××省××县人"（籍贯）的顺序，取第一个出现的地名，原样抄录地名本身。案发地、抓获地、作案地点都不算来源地。
3. residence_text："住、现住、暂住、住所地、家住"后面的地名，原样抄录。
4. segment：origin_text 出自哪一段，取值 "当事人" / "指控" / "查明" / "NA"。
5. evidence：支撑 origin_text 的原文摘录，不超过 20 个字；NA 时填 ""。
6. 只输出一个 JSON 对象，不要任何解释。

输出格式（所有 value 都用字符串）：
{"origin_text": {"value": "...", "evidence": "..."}, "residence_text": {"value": "...", "evidence": ""}, "segment": {"value": "...", "evidence": ""}}
